# Produção publicada

Cada arquivo aqui é a produção de um dia, no formato `AAAA-MM-DD.json`.

O gestor gera pelo próprio aplicativo — **Configuração → Lançar → Publicar o
dia** — e envia o arquivo para esta pasta no repositório. A partir daí toda a
equipe vê o mesmo placar, cada um no seu link.

Enquanto o dia não é publicado, o aplicativo fica em Modo de Espera: funciona
por inteiro e as telas dependentes de produção mostram estado de espera, sem
número inventado.

Os arquivos guardam apenas o que o ranking precisa: nome, data, horário,
pedidos e faturamento.
